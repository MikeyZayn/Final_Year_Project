# THEMBA React frontend

This is the React/Vite frontend for the THEMBA Progressive Web Application.

## Current scope

- Role-aware login and registration prototype
- Passenger trip, fare, route and verification flow foundation
- Driver trip manifest and rating foundation
- Operator active-trip engagement and passenger registration foundation
- Administrator trip, approval, complaint and queue workflow foundation
- Light/dark mode

## Run locally

Node.js and npm are required:

```powershell
npm install
npm run dev
```

The Django API will later replace the local demo state in `src/App.jsx`.
